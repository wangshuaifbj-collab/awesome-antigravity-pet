# 随机发现（宠物扭蛋机）

## 目标

让用户在不离开画廊的情况下快速发现没有主动搜索过的宠物。这个功能是免费的探索工具，不涉及金币、付费抽取、稀有度或任何现金奖励。

## 入口与交互

- 入口放在画廊工具栏的排序控件旁，按钮名称为“随机发现”。
- 桌面端打开居中弹层；移动端打开底部抽屉，不新增侧边栏或独立导航页面。
- 初始状态提供“单抽”和“三连抽”。
- 抽取完成后展示宠物图片、名称、作者、分类，以及“查看”“安装”和“再抽一次”。
- 关闭后回到原来的画廊位置，不改变当前搜索和分类筛选。

## 抽取规则

宠物目录来自构建时生成的 `pets.generated.json`，不调用实时统计接口，也不增加 Worker 请求。

1. 只从当前目录中选择拥有可用预览资源的宠物。
2. 先按 `canonical_key` 分组，再随机选择角色组；同一轮不会出现同一个角色的两个版本。
3. 角色组内再随机选择作者版本，因此同一角色的不同作者仍有机会被发现。
4. 三连抽最多返回三个不同角色；目录不足时返回实际可用数量。
5. 使用浏览器随机源进行普通随机选择；它不是安全抽奖，也不承诺固定概率或奖励价值。

## 可访问性与体验

- 弹层使用 `role="dialog"`、标题关联、Escape 关闭和焦点回收。
- 打开弹层时锁定背景滚动，点击遮罩可以关闭。
- `prefers-reduced-motion: reduce` 下不播放延迟揭晓动画。
- 所有操作按钮提供当前语言的可读名称；图片使用宠物本地化名称作为替代文本。

## 国际化

扭蛋机文案随现有五种语言切换：English、简体中文、한국어、日本語、Español。宠物名称、作者和投稿描述仍遵循目录本身的本地化字段；缺少翻译时回退原始内容，不自动臆造作者文本。

## 验收标准

- 桌面端和移动端都能从画廊工具栏打开扭蛋机。
- 单抽和三连抽不会在同一轮重复 `canonical_key`。
- 结果卡片能打开宠物详情并调用现有安装菜单。
- 关闭、Escape、遮罩点击和减少动态效果均正常。
- 不产生新的实时统计请求，不改变现有筛选、排序、安装和点赞行为。
